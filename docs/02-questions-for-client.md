# 02. Противоречия и пробелы в ТЗ — вопросы заказчику

Закрыть до финальной оценки. Колонка «Предложение» — наш вариант по умолчанию, если заказчик не против.

| # | Вопрос / проблема | Почему важно | Предложение |
|---|---|---|---|
| Q1 | **Шрифты Fraunces и Work Sans не поддерживают кириллицу** (см. [07-design-findings.md](07-design-findings.md)) | Русский текст отрисуется системным шрифтом — сайт не будет похож на макет | Дизайнер выбирает замену с кириллицей (Lora / Literata / Cormorant / Playfair Display / Spectral + Manrope / Onest / Golos Text / Commissioner / Inter) |
| Q2 | **Контраст палитры** не проходит WCAG AA, а ТЗ требует контрастность | Требование приёмки (п. 7) противоречит палитре (п. 8) | Затемнить вторичные цвета; терракоту — только для крупного текста/декора |
| Q3 | Промокоды в админке «опционально», но поле промокода в корзине есть | Без админки промокодов поле бессмысленно | Считаем промокоды обязательными (процент/сумма, мин. сумма, срок, лимиты) |
| Q4 | Тумблер «напоминания о записи» в ЛК | Записи живут в YCLIENTS; сайт их напоминаниями не управляет | Убрать или превратить в маркетинговую подписку |
| Q5 | Вход / восстановление пароля по телефону, «SMS-дублирование» | Нужен SMS-шлюз (деньги, интеграция, антифрод); в ТЗ SMS нет | Вариант А: телефон только как логин, сброс — через email. Вариант Б: SMS-OTP через белорусский шлюз |
| Q6 | Статусы смешивают оплату и выполнение | При оплате наличными «оплачен» идёт после «отправлен» | Два поля: статус оплаты и статус выполнения; в ЛК — формулировки ТЗ |
| Q7 | «Хиты продаж» в списке категорий | Это признак товара, а не категория | Флаг `is_bestseller` + псевдо-фильтр |
| Q8 | Гостевой заказ без регистрации — не описан | Влияет на конверсию и на защиту страниц заказа | Разрешить; после заказа предложить создать аккаунт |
| Q9 | **Варианты товара** (объём 50/200 мл, тон) | Меняет модель данных (товар → варианты) | Спросить сейчас; если нет — простая модель без вариантов |
| Q10 | **Где ведутся остатки?** Продаётся ли та же косметика офлайн (склад YCLIENTS / 1С / МойСклад / Excel)? | Два учёта → остаток на сайте врёт | Синхронизация по API или регламент; источник истины — один |
| Q11 | ЕРИП — нужен? | Почти всегда ожидается в РБ; оплата приходит с задержкой; домен .by без редиректов | Если да — через bePaid, отдельная логика резерва |
| Q12 | Эквайер: bePaid или webpay? | Разные API, договор с банком | Выбрать в неделю 0, сразу подать заявку |
| Q13 | Матрица «доставка × оплата»: почта + наличные = наложенный платёж? | Нужно для валидации чекаута | Зафиксировать таблицу допустимых сочетаний |
| Q14 | Доставка: интеграция или ручные тарифы? Зоны, цены, порог бесплатной доставки? | Объём работ | MVP — ручные тарифы по зонам; API Европочты/Белпочты — позже |
| Q15 | «Спросить у консультанта» — что делает? | Не описано | Ссылка в Telegram/Viber с названием товара |
| Q16 | Отзывы о товарах: кто пишет (все / зарегистрированные / только купившие), модерация? | Не описано, но рейтинг и таб «Отзывы» есть | Только зарегистрированные, премодерация, метка «купил» |
| Q17 | Возврат денег за отменённый оплаченный заказ | Не описано | Вручную в кабинете эквайера; в админке — статус «возврат» |
| Q18 | Удаление аккаунта vs. хранение заказов | Заказы нужны бухгалтерии | Анонимизация ПД, заказы сохраняются |
| Q19 | Карта на главной (контакты — блок главной) | Тяжёлая JS-карта убивает PageSpeed | Статичная картинка + загрузка карты по клику / ссылка на Яндекс.Карты |
| Q20 | Мессенджеры — «кнопки/виджеты» | Чат-виджеты бьют по скорости | Обычные ссылки/иконки |
| Q21 | Методика замера PageSpeed ≥ 90 | Измеримый критерий приёмки | Lighthouse mobile, медиана 5 прогонов, конкретные URL, финальный контент, после согласия на cookie |
| Q22 | Метрика и GA — оба? Вебвизор? | Скорость, трансграничная передача ПД (GA → США) | Метрика обязательно, GA — по решению юриста |
| Q23 | Исходник макета (HTML/CSS артефакт) | Можно переиспользовать в Blade; нужны состояния (ошибки, пусто, загрузка, 320px) | Запросить исходник + список недостающих состояний |
| Q24 | Доступ к API YCLIENTS, ID компании, ID формы виджета, ссылка на кабинет клиента | Синхронизация услуг, глубокие ссылки | Запросить доступы в неделю 0 |
| Q25 | Реквизиты для сайта: юрлицо/ИП, УНП, номер в Торговом реестре, режим работы | Обязательная информация интернет-магазина РБ, проверка эквайером | Получить до запуска |
| Q26 | Хостинг в РБ, домен (.by?), регистрация в БелГИЭ | Требование Указа №60 | Выбрать хостера (желательно с аттестованной платформой) в неделю 0 |
| Q27 | Кто получает уведомления о заказах (email-адреса), нужен ли Telegram | Настройки | Email + Telegram-бот администратору |
| Q28 | Сроки и формат передачи контента (товары: состав, применение, фото) | Классическая причина срыва запуска | Шаблон Excel для импорта + дедлайн |
