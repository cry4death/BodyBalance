## Коротко

- **Стек:** PHP 8.4, Laravel 13, Filament 5 (админка), Blade + Livewire 4 + Alpine, Tailwind 4, MySQL 8 / PostgreSQL, Redis. Магазин — свой модуль.
- **Блокеры до старта:**
  1. Шрифты макета Fraunces и Work Sans **не поддерживают кириллицу** — нужна замена от дизайнера.
  2. Палитра не проходит требование ТЗ по контрасту (WCAG AA).
  3. Юридические требования РБ: хостинг в РБ + БелГИЭ → Торговый реестр, договор эквайринга — длинные сроки, запускать в неделю 0.
- **Главный технический риск:** оплата и остатки (гонки, вебхуки, повторная оплата, срок резерва).
- **Оценка:** 12–15 недель на одного full-stack, 8–10 — на двоих.
