## Пишем сами (основной объём работы)

1. **Вёрстка по макету**: дизайн-система Blade-компонентов, все страницы, плюс состояния, которых в макете нет (пустая корзина, нет в наличии, ошибки валидации, загрузка, 320px).
2. **Каталог**: фильтры/сортировка/поиск/пагинация с ЧПУ и canonical; «хит» — флаг; популярность = `sales_count` + ручной вес.
3. **Корзина**: в БД, гость по cookie, слияние при логине, счётчик в шапке.
4. **Промокоды**: тип, значение, мин. сумма, сроки, лимиты (с блокировкой при исчерпании).
5. **Доставка**: тарифы по зонам, порог бесплатной доставки.
6. **Чекаут**: матрица доставка×оплата, валидация, резерв остатков, создание заказа в транзакции.
7. **Платёжный модуль**: драйвер bePaid/webpay, вебхуки, идемпотентность, истечение резерва и платёжной сессии, ночная сверка.
8. **Заказы**: статусы и переходы, история, письма при смене статуса, ресурс в админке, экспорт.
9. **ЛК**: адреса, профиль, тумблеры уведомлений, связывание соц. аккаунтов, удаление = анонимизация.
10. **Отзывы о товарах**: форма, модерация, пересчёт рейтинга.
11. **YCLIENTS**:
    - свои кнопки через класс `ms_booking` (стандартный способ YCLIENTS для кастомных кнопок);
    - загрузка скрипта по клику/видимости, таймаут, fallback-модалка с телефоном/мессенджерами;
    - рубильник в админке «запись только по телефону»;
    - опционально — синхронизация справочника услуг по API (cron + кнопка «синхронизировать сейчас» + таблица соответствия категорий).
12. **SEO-слой**: шаблоны мета с fallback, JSON-LD, robots по окружению, 301-редиректы при смене слага, управление редиректами в админке.
13. **Аналитика**: `dataLayer` в формате GA4 e-commerce (`view_item`, `add_to_cart`, `remove_from_cart`, `begin_checkout`, `purchase`). Яндекс.Метрика понимает этот формат (при `ecommerce: "dataLayer"`) — один код на оба счётчика. `purchase` — ровно один раз (флаг в заказе).
14. **Cookie-баннер** с реальным выбором (технические / аналитика), счётчики — только после согласия; журнал согласий.

## Почему не готовая e-commerce платформа

| Вариант | Плюсы | Минусы | Вердикт |
|---|---|---|---|
| **Lunar** (lunarphp) | Каталог, варианты, цены, скидки, корзина, заказы, ассоциации товаров, админка на Filament | Стабильная **1.5.0 (26.08.2026) требует Filament ^4.1**, ветка 2.0 под Filament 5 — alpha. Админка (типы товаров, каналы, группы покупателей, налоги) перегружена для студии; кривая обучения | Не берём. Вернуться, если появятся варианты, тысячи SKU, сложные скидки |
| **Bagisto** | Готовый магазин целиком | Отдельное приложение со своей админкой (не Filament) и темой; встраивать студийную часть и точный макет дороже | Не берём |
| **Aimeos** | Очень мощный | Избыточен, сложен | Не берём |
| **Свой модуль** | Полный контроль, простая русская админка ровно под задачи, точное соответствие макету | Пишем корзину/заказы/промокоды сами | **Берём**. Бэкенд магазина такого масштаба ≈ 3 недели |
