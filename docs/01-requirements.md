# 01. Требования (базовый чек-лист)

Выжимка обязательных требований из ТЗ ([source/TZ-Body-Balance.pdf](source/TZ-Body-Balance.pdf)). В скобках — пункт ТЗ.
Отметка `(опц.)` — в ТЗ помечено как опциональное. Пункты с ⚠ имеют открытые вопросы — см. [02-questions-for-client.md](02-questions-for-client.md).

## А. Сайт студии

- [ ] **А1. Главная** — одна длинная страница, 12 блоков в фиксированном порядке (п. 4):
  - [ ] А1.1 Шапка: sticky при скролле; логотип; меню «Услуги / О студии / Специалисты / Магазин / Контакты»; кнопка «Записаться» → виджет YCLIENTS; иконка корзины со счётчиком.
  - [ ] А1.2 Hero: название студии, слоган «Баланс тела и кожи в одной студии», CTA «Записаться» → YCLIENTS.
  - [ ] А1.3 Услуги: 5 карточек (фото, краткое описание, ссылка на страницу категории).
  - [ ] А1.4 О студии: 2–3 абзаца + галерея фото интерьера.
  - [ ] А1.5 Специалисты: карточки (фото, имя, специализация/квалификация, описание).
  - [ ] А1.6 Превью магазина: 4 популярных товара с ценой и «В корзину», ссылка «Перейти в магазин».
  - [ ] А1.7 Бренды: Comfort Zone, La Sultane de Saba, JWPro, Germaine de Capuccini, PHformula.
  - [ ] А1.8 Отзывы: 3 отзыва (текст + имя).
  - [ ] А1.9 Преимущества: 4 пункта.
  - [ ] А1.10 FAQ: аккордеон.
  - [ ] А1.11 Контакты: адрес (д. Копище, ул. Леонардо да Винчи, 2), «Написать в Telegram», карта (п. 6.4) ⚠.
  - [ ] А1.12 Футер: логотип, политика конфиденциальности, публичная оферта, «Доставка и оплата», иконки Instagram / Viber / Telegram.
- [ ] **А2. 5 страниц категорий услуг** (п. 2, 3.1): Массаж для тела, Уходы для тела, Массаж для лица, Уходы для лица, Пилатес на реформере. Структура: hero с описанием подхода; таблица процедур (название, длительность, цена фикс/«от»); блок специалиста, ведущего направление; FAQ 3–4 вопроса; «Записаться».
- [ ] **А3. Справочник услуг** «Категория → Процедура» (п. 2): название, краткое описание, длительность, цена, признак «от», фото. Соответствие справочнику YCLIENTS — в идеале автосинхронизация, минимум — ручная сверка.
- [ ] **А4. Служебные страницы** (п. 3.4): политика конфиденциальности / согласие на обработку ПД; публичная оферта / условия продажи и возврата; доставка и оплата. Контент — от заказчика/юриста, вёрстка — общий шаблон текстовой страницы.

## Б. Онлайн-запись (YCLIENTS) (п. 6.1)

- [ ] Б1. Запись только через виджет YCLIENTS (iframe/JS), без собственной формы.
- [ ] Б2. Вызов виджета: шапка, hero, страница каждой категории (встроенно и/или по кнопке).
- [ ] Б3. Через виджет: выбор услуги (категория → процедура, соответствуют сайту), специалиста, времени; ввод контактов; подтверждение; актуальные слоты; подтверждение клиенту (SMS/email/push — настройка YCLIENTS).
- [ ] Б4. Асинхронное подключение — виджет не замедляет загрузку (п. 6.5).
- [ ] Б5. При недоступности YCLIENTS — понятная заглушка с телефоном/мессенджерами, не «белый экран» (п. 7).
- [ ] Б6. Стилизация в фирменные цвета в пределах настроек YCLIENTS (п. 8).
- [ ] Б7. В ЛК — блок-ссылка «Открыть кабинет YCLIENTS» (п. 3.3, 5.4).
- [ ] Б8. Цели записи в аналитике — «по возможности» (п. 6.4).

## В. Каталог (п. 5.1, 5.2)

- [ ] В1. Фильтр по бренду: 5 приоритетных + расширенный список (финальный — согласовать).
- [ ] В2. Фильтр по категории: Все, Сыворотки, Кремы, Очищение, SPF, Уход за телом, Хиты продаж ⚠.
- [ ] В3. Поиск по названию/бренду; сортировка (по умолчанию «по популярности»); пагинация.
- [ ] В4. Карточка в каталоге: фото, бренд, название, категория, цена, бейдж «Хит»/«Новинка» (опц.), «В корзину».
- [ ] В5. Страница товара: галерея (основное фото + миниатюры); бейдж; рейтинг и количество отзывов; бренд, название, категория, цена; селектор количества + «Добавить в корзину»; «Спросить у консультанта» ⚠; ключевые преимущества (буллеты с галочкой).
- [ ] В6. Табы «Описание», «Состав», «Как применять», «Отзывы» + блок характеристик.
- [ ] В7. «С этим продуктом покупают» — 4 карточки; «Похожие товары» — 4 карточки.
- [ ] В8. **Скрытое требование:** модуль отзывов о товарах с рейтингом (+ модерация) ⚠.

## Г. Корзина, оформление, оплата, заказы (п. 5.3)

- [ ] Г1. Корзина: фото, бренд, название, категория, количество +/−, цена; удаление; сводка (товары, доставка, итого); промокод ⚠; «Оформить заказ»; «Продолжить покупки».
- [ ] Г2. Чекаут — одна страница, 3 шага:
  - [ ] контакты (имя, телефон, email);
  - [ ] способ получения: самовывоз (бесплатно) / курьер по городу / почта по стране, адрес доставки;
  - [ ] способ оплаты: картой онлайн / картой при получении (только самовывоз) / наличными при получении ⚠;
  - [ ] комментарий к заказу;
  - [ ] сводка в сайдбаре (товары, доставка, итого), «Подтвердить заказ».
- [ ] Г3. Онлайн-оплата: bePaid или webpay ⚠.
- [ ] Г4. Доставка: интеграция со службами или ручной расчёт по городу/региону ⚠.
- [ ] Г5. Страница подтверждения: галочка, номер и дата, состав, способы получения и оплаты, итог, «Продолжить покупки» / «На главную».
- [ ] Г6. Email клиенту и администратору о новом заказе.
- [ ] Г7. Статусы: новый / в обработке / оплачен / отправлен / выполнен / отменён; отображаются в ЛК ⚠.
- [ ] Г8. Остатки/наличие; корректная обработка «товар закончился во время оформления»; защита от повторной оплаты одного заказа (п. 7).
- [ ] Г9. UX-сценарий строго по макету: карточка → корзина → чекаут в 3 шага → подтверждение (п. 8).

## Д. Авторизация и личный кабинет (п. 3.3, 5.4, 6.2)

- [ ] Д1. Регистрация: имя, email/телефон, пароль + подтверждение, согласие с офертой и политикой ПД; Google и Яндекс ID.
- [ ] Д2. Вход: email/телефон + пароль ⚠; Google OAuth; Яндекс ID; ссылка на регистрацию.
- [ ] Д3. Восстановление пароля («Забыли пароль?») ⚠.
- [ ] Д4. Сессии, хэширование паролей, rate limiting от подбора.
- [ ] Д5. Ошибка/отказ OAuth-провайдера обрабатывается, fallback — вход по email/телефону (п. 7).
- [ ] Д6. Мои заказы: номер, дата, статус (цветом), состав, сумма; переход к деталям.
- [ ] Д7. Адреса: список, метка («Дом»/«Работа»), основной; добавление (получатель, телефон, город, улица/дом/квартира, «сделать основным»), редактирование, удаление.
- [ ] Д8. Профиль: имя, телефон, email, дата рождения; смена пароля; тумблеры уведомлений — статус заказа, напоминания о записи ⚠, акции и новости, SMS-дублирование ⚠; удаление аккаунта ⚠.
- [ ] Д9. (опц.) Избранное (wishlist).

## Е. Админ-панель (п. 5.5, 6.3)

- [ ] Е1. Редактирование текстов и фото на всех страницах.
- [ ] Е2. Услуги: категории и процедуры, цены (CRUD).
- [ ] Е3. Товары: CRUD (фото, название, бренд, категория, описание, состав, цена, остатки/наличие).
- [ ] Е4. Бренды и категории каталога.
- [ ] Е5. Заказы: просмотр, контакты покупателя, состав, смена статуса.
- [ ] Е6. Выгрузка заказов в Excel/CSV.
- [ ] Е7. Отзывы (CRUD), специалисты (CRUD).
- [ ] Е8. Title / Description / H1 для каждой страницы и товара (п. 6.5).
- [ ] Е9. (опц. в ТЗ, фактически нужно ⚠) Промокоды/скидки.

## Ж. Интеграции (п. 6.4)

- [ ] Ж1. YCLIENTS (виджет; API — по возможности).
- [ ] Ж2. Google OAuth, Яндекс ID.
- [ ] Ж3. Эквайринг bePaid / webpay.
- [ ] Ж4. Мессенджеры: Telegram, Viber, Instagram (кнопки/ссылки).
- [ ] Ж5. Карта: Яндекс.Карты или Google Maps.
- [ ] Ж6. Яндекс.Метрика и/или GA4 с e-commerce-трекингом заказов; цели на запись YCLIENTS по возможности.

## З. SEO (п. 6.5)

- [ ] З1. Человекопонятные URL.
- [ ] З2. Редактируемые Title/Description/H1 (см. Е8).
- [ ] З3. Автогенерация sitemap.xml и robots.txt.
- [ ] З4. Schema.org: LocalBusiness, Product + Offer (цена, наличие), Review.
- [ ] З5. alt у всех изображений.
- [ ] З6. Оптимизация изображений, lazy load, пагинация в каталоге, асинхронный YCLIENTS.

## И. Нефункциональные требования / критерии приёмки (п. 7, 8)

- [ ] И1. Адаптивность от 320px, mobile-first (в т.ч. чекаут, вход/регистрация, запись с телефона).
- [ ] И2. Кроссбраузерность: последние Chrome, Safari, Firefox, Edge.
- [ ] И3. **PageSpeed Insights ≥ 90 (мобайл) для главной и каталога** ⚠ (методику зафиксировать).
- [ ] И4. HTTPS; защита от спам-ботов; безопасное хранение ПД, паролей, заказов; резервное копирование БД.
- [ ] И5. Доступность: контраст ⚠, читаемые размеры шрифта, навигация с клавиатуры.
- [ ] И6. Отказоустойчивость магазина, записи, авторизации (см. Г8, Б5, Д5).
- [ ] И7. Дизайн по макету: палитра, типографика ⚠, компоненты (.btn-primary, .btn-ghost, .chip, карточки с радиусом 14–20px, поля форм, toggle).

## К. Вне зоны сайта (явно)

- Расписание, свободные окна, загрузка мастеров, история записей — в YCLIENTS, на сайте не дублируются.
- Юридические тексты — готовит заказчик/юрист.
- Фотосъёмка — заказчик.
