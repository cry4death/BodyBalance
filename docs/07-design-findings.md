# 07. Проверка макета (2026-10-06)

## 1. Шрифты: нет кириллицы ❗

Проверено через Google Fonts CSS API (`https://fonts.googleapis.com/css2?family=...`) — список `unicode-range` подмножеств. Скрипт: [tools/check-fonts.sh](tools/check-fonts.sh).

| Шрифт (из ТЗ) | Роль | Подмножества |
|---|---|---|
| **Fraunces** | заголовки | latin, latin-ext, vietnamese — **кириллицы нет** |
| **Work Sans** | основной текст | latin, latin-ext, vietnamese — **кириллицы нет** |

**Следствие:** весь русский текст будет отрисован fallback-шрифтом (Times/Arial и т.п.) — сайт не будет похож на макет. Вероятно, макет согласовывался уже с fallback-шрифтами, без понимания этого.

**Кандидаты на замену (кириллица проверена тем же способом):**

| Заголовки (serif) | Текст (sans) |
|---|---|
| Lora — cyrillic, cyrillic-ext | Manrope — cyrillic, cyrillic-ext |
| Literata — cyrillic, cyrillic-ext | Onest — cyrillic, cyrillic-ext |
| Cormorant — cyrillic, cyrillic-ext | Golos Text — cyrillic, cyrillic-ext |
| Playfair Display — cyrillic | Commissioner — cyrillic, cyrillic-ext |
| Spectral — cyrillic, cyrillic-ext | Inter — cyrillic, cyrillic-ext |

Решение — за дизайнером. Для производительности шрифты подключаем self-hosted (woff2, subset), а не с Google Fonts.

## 2. Контраст палитры (WCAG 2.x)

Скрипт: [tools/contrast.py](tools/contrast.py). Нормы AA: обычный текст ≥ 4.5:1, крупный (≥24px или ≥18.66px bold) ≥ 3:1, границы элементов управления ≥ 3:1.

| Цвет текста | на #FAF8F3 (Ivory) | на #F1ECDF | на #EFE8D8 | Вывод |
|---|---|---|---|---|
| #2B2B26 основной | 13.40 | 12.06 | 11.65 | ✅ |
| #55534A вторичный | 7.27 | 6.54 | 6.32 | ✅ |
| #8A876F вторичный | **3.43** | **3.08** | **2.98** | ❌ для обычного текста, только крупный |
| #A79F87 вторичный | **2.49** | **2.24** | **2.16** | ❌ даже для крупного |
| #4A5D4E шалфей | 6.67 | 6.00 | 5.80 | ✅ |
| #C97B5C терракота | **3.06** | **2.75** | **2.66** | ❌ для обычного текста |

| Комбинация | Контраст | Вывод |
|---|---|---|
| Белый на шалфее #4A5D4E (.btn-primary) | 7.08 | ✅ |
| Белый на терракоте #C97B5C | **3.25** | ❌ для обычного текста (кнопки с мелким текстом) |
| Ivory на терракоте | **3.06** | ❌ для обычного текста |
| Граница полей #E7E1D4 на Ivory | **1.23** | ❌ (нужно 3:1, если граница — единственный признак поля) |

**Рекомендации дизайнеру:**
- #A79F87 — только декор (разделители, иконки-украшения), не текст.
- #8A876F — только крупный текст, либо затемнить до ≥ 4.5:1.
- Терракота — акценты/крупные заголовки; для кнопок с текстом — затемнить.
- Поля форм — более тёмная граница или фон поля, отличный от фона страницы.

## 3. Что ещё запросить у дизайнера

- Исходник артефакта (HTML/CSS) — ТЗ упоминает классы `.btn-primary`, `.btn-ghost`, `.chip`.
- Состояния: hover/focus (видимый фокус для клавиатуры!), disabled, ошибки валидации, пустая корзина, «нет в наличии», загрузка, успех.
- Мобильные макеты 320–375px для каталога, корзины, чекаута, ЛК.
- Заглушка «YCLIENTS недоступен», страницы 404/500.
- Табы «Состав», «Как применять», «Отзывы» (в макете раскрыто только «Описание»).
